Place your design images (the UI screens you provided) in this folder with these filenames:

- `ui-1.png` — left sidebar / upload panel
- `ui-2.png` — main/top panel (header + content)
- `ui-3.png` — main/bottom-left panel
- `ui-4.png` — main/bottom-right panel
- `ui-5.png` — optional right assistant rail (large screens)

After adding the images, run the frontend dev server and the new design will be displayed automatically.

Tip: use PNG files sized around 1600px width for good quality.
